# FVCKSIMILE Media Kit

Pagina pubblicata su https://mediakit.fvcksimile.com (Netlify, deploy automatico da questo repository).

- `data.js` — numeri, video e testi: è l'unico file da aggiornare ogni settimana.
- `index.html` — layout, stile e testi fissi (IT/EN).
- `logo.png` — logo FVCKSIMILE.

Versione inglese: aggiungere `#en` all'indirizzo.
